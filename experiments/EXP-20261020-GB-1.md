# EXP-20261020-GB-1: Why is C4's EPR lift of the motif prior not resolved, and how many never-used datasets would a new study need?

## 1. Registration (before the run)

- type: **exploratory** (descriptive diagnosis and planning numbers from committed rows). It cannot
  change the verdict, text or status of C4 and cannot back a claim.
- owner: GB (agent-prepared)   issue: #127   registered: 2026-10-20 (the pushed commit of this file =
  the pre-registration)
- follows: EXP-20260925-LM-2 (C4), section 3: on EPR, a secondary endpoint, `pearson_motif -
  pearson_signed` is not resolved in either arm (auto +0.120 [-0.046, +0.286], p_Holm 0.219;
  baseline +0.152 [-0.014, +0.318], p_Holm 0.105; n = 20). Point 15 of the Phase 0 plan, step 15-1.
- not blind: a preliminary version of these numbers was computed on 2026-10-18/19 from the same
  committed CSV while the plan was drafted (agent scratch files, not in git). This record fixes the
  analysis and makes it reproducible; the tests of `benchmarks/epr_power.py` pin those preliminary values.
- questions: (a) what the 20 per-dataset EPR differences look like (spread, tails, influence of single
  datasets, size relative to the AUPRC-ratio lift of the same pair); (b) which effect n = 20 could
  detect with C4's procedure; (c) how many never-used datasets a new study with the same paired t
  would need, for EPR effects from +0.05 to +0.20 and if the true effect equalled C4's estimate.
- hypothesis: none is tested. Expectation stated now: C4 did not resolve the EPR lift because n = 20
  is small for an SD of differences of about 0.35, not because of heavy tails or one dataset.
- primary endpoint: none (no test). Reported quantities, per arm: mean, SD and dz (mean / SD) of the
  per-dataset EPR differences; the smallest detectable effect at n = 20; n for 80% and 90% power.
- unit of analysis: dataset (n = 20, the committed rows of C4). Never edges, cells or contexts.
- datasets: none downloaded. Inputs: `benchmarks/results/EXP-20260925-LM-2/all_rows_real.csv` and
  `benchmarks/results/EXP-20260925-LM-2/REPORT_REAL.md` as committed on main (6917c88).
- gate (fixed now): `real_bench.models_section`, the registered report code, run on the committed rows
  must print EPR declared-comparison lines (both arms) that are found verbatim in the committed
  `REPORT_REAL.md`; otherwise the script stops and reports nothing.
- exclusion rules: those of the registered report (a dataset without a score for either model leaves
  the pair; 20/20 have both). No outlier removal.
- comparison family: none, no test is run. C4's registered family (4 directed hypotheses per metric and
  arm, Holm) is only reprinted by the gate.
- methods: paired differences; t quantities as in `compare_units` (paired t, two-sided 95% interval,
  one-sided p in each direction); Shapiro-Wilk, skew, excess kurtosis and the t with each dataset left
  out (descriptive); percentile bootstrap of dz (20,000 resamples, seed 42, 10th and 90th percentiles);
  chi-square 95% interval of the SD. Power from `grnbench.eval.power`: the G*Power matched-pairs model
  (Faul et al. 2007, doi:10.3758/BF03193146; noncentral t), one-sided, at alpha/4 (first Holm step of
  C4's family of 4), alpha/3 (the same family once the other pair is rejected first) and alpha/2 (a
  family of one pair), alpha 0.05; grid n = 20, 60, 100, 120, 150, 200. A signed-rank sensitivity uses
  the asymptotic relative efficiency 3/pi and its minimum 0.864 (Hodges and Lehmann 1956,
  doi:10.1214/aoms/1177728261). The log of the EPR ratio and the AUPRC-ratio dz are scale diagnostics
  only: Demsar 2006 (JMLR 7:1-30) doubts averaging ratios, and no change of scale is proposed.
- no observed power: power at the achieved n = 20 is reported only as the smallest detectable effect,
  never computed from C4's estimate. Numbers at C4's estimate are a planning scenario for a new study,
  shown with the bootstrap band of dz.
- smallest effect that matters: none declared here. +0.10 EPR is a planning scenario (the plan proposes
  it for a future confirmatory record; not decided).
- seeds: bootstrap seed 42; nothing else is random.

## 3. Results (copied from the generated report, not typed)

- status: done (2026-10-20, local, a few seconds; run from 7b1f9d1, whose code equals 341e98c)
- produced by: `python benchmarks/epr_power.py --out benchmarks/results/EXP-20261020-GB-1` ->
  `benchmarks/results/EXP-20261020-GB-1/POWER.md` (every number below comes from it), `power.json`,
  figure `power_epr.png`.
- gate: passed. The registered code reprints the four EPR lines of C4's `REPORT_REAL.md` verbatim
  (auto +0.120 [-0.046, +0.286], p_Holm 0.219; baseline +0.152 [-0.014, +0.318], p_Holm 0.105).
- (a) diagnosis, auto / baseline arm:
  - SD of the per-dataset differences 0.355 / 0.355 (95% interval 0.270 to 0.518); dz 0.34 / 0.43
    (bootstrap 10-90%: 0.06 to 0.68 / 0.14 to 0.86).
  - no heavy tails (excess kurtosis -0.58 / -0.65), but the baseline arm is skewed to the left: skew
    -0.13 / -0.70, Shapiro-Wilk p 0.93 / 0.07; 13/20 and 14/20 differences are positive.
  - single datasets (`POWER.md`, the registered report code rerun with each dataset left out): in the
    auto arm no single dataset decides, the verdict stays unresolved in all 20 drops (t with one dataset
    left out 1.14 to 2.05). In the baseline arm it changes in 2 of 20 drops: without
    `10x-3-v3__homo-sapiens__prostate-gland__20de8570` or `10x-3-v3__homo-sapiens__respiratory-airway__eec804b9`
    (its two most negative differences, -0.558 and -0.519) the registered code reports `pearson_motif`
    supported on the other 19 (+0.190 [+0.035, +0.345], p_Holm 0.0288; +0.188 [+0.030, +0.345], p_Holm
    0.0331); t with one dataset left out 1.61 to 2.57.
  - the two models' EPR correlate 0.90 / 0.92 across datasets. Mean EPR (auto) 2.448 for `pearson_motif`
    and 2.328 for `pearson_signed`. The same pair on AUPRC ratio has dz 1.90 / 2.10; on EPR the lift is
    small next to the dataset-to-dataset spread of the difference.
  - log of the EPR ratio: dz 0.46 / 0.59 (scale diagnostic only). Part of the spread may come from
    datasets with different EPR ceilings; checking that needs k and prevalence per dataset (step 15-2).
  - Spearman of the difference with `reference_edges` -0.29 / -0.31 (weak; `reference_edges` is not the
    EPR's k).
- (b) sensitivity: with n = 20 the smallest effect detectable with 80% power is dz 0.74 at alpha/4 and
  0.66 at alpha/2, i.e. +0.262 and +0.234 EPR. C4's estimates (+0.120 / +0.152) are below that.
- (c) planning, never-used datasets, same paired t, SD 0.355 (auto arm; with the baseline arm's SD every
  n in `POWER.md` is the same or one fewer):

  | EPR effect | family of 4, alpha/4: n for 80% / 90% | one pair, alpha/2: n for 80% / 90% |
  |---|---|---|
  | +0.10 | 123 / 159 | 101 / 135 |
  | +0.12 (about C4's auto estimate) | 86 / 112 | 71 / 94 |
  | +0.15 (about C4's baseline estimate) | 56 / 72 | 46 / 61 |

  With the SD's 95% interval instead, +0.10 at alpha/2 needs 60 to 213 datasets. If the true effect
  equalled C4's estimate: auto 86 / 80 / 71 datasets for 80% at alpha/4 / alpha/3 / alpha/2, baseline
  55 / 51 / 45; the bootstrap band of dz makes this scenario very uncertain (auto at alpha/3: 22 to 2714).
  By n (auto arm, alpha/4 to alpha/2): at n = 120 the power is 0.792 to 0.865 for +0.10 and the
  smallest effect at 80% is +0.101 to +0.091; at n = 200 the power is 0.957 to 0.978 for +0.10 and the
  smallest effect is +0.078 to +0.071.
  All of (a)-(c) treat the 20 dataset ids as independent units, while C4's claim notes that 3 pairs
  share a source study (`paper/CLAIMS.md`, C4); a new study should count independent source studies,
  not dataset ids.
