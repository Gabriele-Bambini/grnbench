# EXP-20261002-LM-1: Does the motif prior lift Pearson, GRNBoost2 and RegDiffusion on 20 fresh real datasets?

## 1. Registration (before the run)

- type: **confirmatory** (pre-registration = the commit that adds this file, pushed before any
  model below was run on any dataset of this list)
- owner: LM (agent-run)   issue: #27   registered: 2026-10-02
- follows: EXP-20260925-LM-2 (C4, Pearson) and EXP-20260926-LM-1 (C5, GRNBoost2 and RegDiffusion),
  both on the same 20 datasets. Section 5 of EXP-20260926-LM-1 names this run: the same hypotheses
  on datasets never used by any experiment, which removes the "seen in LM-2" caveat of C5 and
  tests whether C4 generalises beyond the set it was found on.
- hypothesis: three co-primary, directional. H1: `pearson_motif` recovers the CollecTRI evaluation
  half better than `pearson_signed`. H2: `regdiffusion_motif` better than `regdiffusion`.
  H3: `grnboost2_motif` better than `grnboost2`. (`<model>_motif` = the model's edges
  rank-producted with the cisTarget motif prior, as in C4 and C5.)
- primary endpoint: AUPRC ratio (AUPRC / prevalence; 1 = random) on the CollecTRI evaluation half,
  **auto** pipeline arm (the engine's screened choice), mean over contexts within a dataset.
- secondary endpoints (reported, not used for H1-H3): EPR; the baseline pipeline arm; each model's
  mean AUPRC ratio against random (1.0), descriptive only; the two non-motif pairs of the family
  below.
- unit of analysis: dataset. Planned n = 20; analysed n = datasets with a score for both members
  of a pair (printed per pair by the report).
- datasets: 20 CELLxGENE datasets chosen on 2026-10-02 by
  `benchmarks/fetch_cellxgene.py --max 20 --max-mb 60 --organisms "Homo sapiens,Mus musculus"
  --exclude-ids experiments/EXP-20261002-LM-1.excluded_ids.txt --exclude-assay targeted` from the
  public listing of that day. Excluded before selection: the 51 dataset ids used by any earlier
  experiment (the 31 of `EXP-20260925-LM-2.excluded_ids.txt` plus the 20 of LM-2 and LM-1).
  The fetched selection is committed with this file as `EXP-20261002-LM-1.datasets.tsv`, and the
  sha256 of every `data.h5ad` and `truth.json` is added to `experiments/datasets.tsv` in the same
  commit. No model of this repo has been run on any of them.
- reference: the registered CollecTRI snapshot (`references/collectri_{human,mouse}.tsv` with the
  sha256 in `experiments/datasets.tsv`, the bytes used by C4 and C5). Issue #21 decided that
  existing claims are tested on their registered snapshots; this run tests whether C4 and C5
  generalise to new datasets, so the reference is held fixed. cisTarget: the registered v10 files.
- exclusion rules (fixed now): (a) a dataset whose sha256 does not match `experiments/datasets.tsv`
  at run time is reported as missing and replaced by nobody (`truth.json` differing only in line
  endings is accepted, `ok-eol`); (b) datasets with fewer than 50 reference edges among their genes
  are not scored (`MIN_REFERENCE_EDGES`); (c) a dataset where a model errors is dropped from the
  pairs involving that model only, and reported; (d) a dataset still unfinished after the job and
  one resubmission of the same commit (TIMEOUT or out of memory) is reported as missing;
  (e) no other exclusion, no outlier removal.
- comparison family: `real_bench.DECLARED_PAIRS` restricted to the models run =
  {(pearson_motif, pearson_signed), (grnboost2_motif, grnboost2), (regdiffusion_motif, regdiffusion),
  (grnboost2, pearson_signed), (regdiffusion, pearson_signed)}, both directions = 10 directed
  hypotheses per metric and arm.
- test: paired t over datasets, two-sided per direction, via `compare_units` for each pair (95%
  interval of the mean paired difference), Holm over the 10 directed hypotheses of the AUPRC ratio /
  auto family, alpha 0.05. For each of H1-H3: **supported** if p_Holm(motif > plain) < 0.05;
  **refuted** if p_Holm(plain > motif) < 0.05; otherwise inconclusive (not evidence of equality).
- primary comparison: pearson_motif > pearson_signed | auprc_ratio | auto; regdiffusion_motif > regdiffusion | auprc_ratio | auto; grnboost2_motif > grnboost2 | auprc_ratio | auto
- smallest effect that matters: none declared.
- seeds: reference split seed 0 (`screen.split_reference`), cell subsample seed 0 (at most 3,000
  cells per context, `MAX_SCORE_CELLS`), scrublet seed 0, RegDiffusion seed 0 (1,000 steps, CPU),
  GRNBoost2 seed 42 (the adapter defaults); regulators = the 150 TFs with most reference targets
  in the data (`MAX_TFS`).
- models: pearson_signed, pearson_motif, regdiffusion, regdiffusion_motif, grnboost2,
  grnboost2_motif (exactly these six).

## 2. How it runs

- code: branch `lm/exp-fresh-motif` from `main` 245ac12 (includes #16, the RegDiffusion
  zero-variance fix that cost EXP-20260926-LM-1 one dataset). `hpc/hpc.sh sync` writes the commit
  to `GIT_COMMIT`; the job runs from a separate cluster checkout `~/grnbench-fresh1` (a copy of the
  synced tree) via `REPO_DIR`, and copies `GIT_COMMIT` into the results as `CODE_COMMIT`. That commit
  must be clean.
- environment: conda env `grnbench` on the cluster, Python 3.11, `requirements/lock-py311.txt` plus
  the RegDiffusion line of its header (regdiffusion 0.2.3, torch CPU), as for EXP-20260926-LM-1.
- data (login node, downloads only; `D=~/grnbench_data_fresh1`, a root holding only this
  experiment's data plus the registered references):
  ```
  python benchmarks/fetch_cellxgene.py --out $D/cellxgene --max 20 --max-mb 60 --organisms "Homo sapiens,Mus musculus" --exclude-ids experiments/EXP-20261002-LM-1.excluded_ids.txt --exclude-assay targeted
  cp -r ~/grnbench_data_lm1/references $D/      # registered bytes, checked below
  python benchmarks/data_manifest.py $D --check experiments/datasets.tsv          # must exit 0
  python benchmarks/data_manifest.py ~/grnbench_data_lm1 --check experiments/datasets.tsv   # cisTarget files, must exit 0
  ```
  A rerun fetches the same files with `fetch_cellxgene.py --out $D/cellxgene --from-manifest
  experiments/EXP-20261002-LM-1.datasets.tsv`.
- commands (one Slurm job, QOS `stud`, 8 CPUs, 32 GB, 24 h; `O=~/gb_runs/EXP-20261002-LM-1`):
  ```
  python benchmarks/real_bench.py plan --data-root $D --out $O/real_tasks.json
  sbatch --time=24:00:00 --export=ALL,REPO_DIR=$HOME/grnbench-fresh1,OUT=$O,SCRIPT=benchmarks/real_bench.py,TASKS=$O/real_tasks.json,REFS=$D/references,CHUNK=100000,MODELS=pearson_signed+pearson_motif+regdiffusion+regdiffusion_motif+grnboost2+grnboost2_motif,KEEP_ARTIFACTS=1,GRNBENCH_CISTARGET_DIR=$HOME/grnbench_data_lm1/cistarget,TMPDIR=$HOME/gb_tmp hpc/engine_bench.sbatch
  python benchmarks/real_bench.py report --out $O --tasks-for-viz $O/real_tasks.json
  ```
- machine: Bocconi HPC, partition/QOS `stud`, 1 job, 8 CPUs (8 dataset workers, one thread each),
  32 GB. Expected cost: EXP-20260926-LM-1 took 1 h 10 min for four models on 20 datasets; the two
  Pearson models add little.
- results: `benchmarks/results/EXP-20261002-LM-1/` (rows, reports, figures within the size rule);
  edges and processed data stay in `~/gb_runs/EXP-20261002-LM-1`.
- report input: `benchmarks/results/EXP-20261002-LM-1`.
- status at registration: data fetched and checked, no model run on it.
