# EXP-20260925-LM-1: Does a motif (sequence) prior lift GRN recovery on real data?

## 1. Registration
- type: exploratory. The comparison family was declared in code (`real_bench.DECLARED_PAIRS`)
  before the run, but there was no committed registration record. Needs a confirmatory rerun
  before it feeds a headline claim.
- owner: LM (agent run on Luca's laptop)
- hypothesis: combining a cisTarget motif prior with a co-expression model improves recovery of
  CollecTRI targets on real scRNA-seq.
- primary endpoint: AUPRC ratio on the CollecTRI evaluation half (selection half used only to choose
  the pipeline, `screen.split_reference`, seed 0); secondary: EPR
- unit of analysis: dataset, n = 12 (CELLxGENE, 8 protocols, human 7 + mouse 5)
- exclusions: PBMC3k (used for development; reported separately as n = 13); a BD Rhapsody 460-gene
  targeted panel (not a transcriptome), removed from tasks.json before the run
- comparison family: 7 pairs x 2 directions per metric and arm (`real_bench.DECLARED_PAIRS`), paired t, Holm
- seeds: reference split seed 0; at most 3,000 cells per context

## 2. How it ran
- code: commit 942cdea of Luca's offline history (its tree is part of the first commit of this repo);
  `CODE_COMMIT` in the results folder
- environment: Python 3.11.9 (Windows), requirements/lock-py311.txt + regdiffusion 0.2.3, torch 2.14.0 CPU
- data: `experiments/datasets.tsv` (cellxgene/*, 10x_pbmc3k/filtered, references/collectri_*, cistarget/*)

- results: `benchmarks/results/engine-2026-09-25-models/` (REPORT.md, test12/, all13/, tasks.json)

## 3. Results
- status: done
- produced by: `python benchmarks/real_bench.py report --out .../test12`
- headline: pearson_motif vs pearson_signed AUPRC ratio +0.229 [95% simultaneous +0.160, +0.297],
  n = 12, paired t two-sided, p_Holm = 9.9e-05; regdiffusion_motif vs regdiffusion +0.222, p_Holm = 8.5e-04;
  grnboost2_motif vs grnboost2 +0.143, p_Holm = 9.6e-06
- null/negative: pearson_motif vs motif_prior AUPRC unresolved (+0.114, p_Holm = 0.43); grnboost2 is
  below pearson_signed (-0.221, p_Holm = 0.046) and at random on EPR (1.02); auto vs baseline cleaning ties.
- verdict: supports (exploratory)
- deviations: scikit-image was not installed, so wherever the plan chose `scrublet` (rows show
  `doublets: scrublet`) doublet calling most likely fell back to the heuristic caller with a warning
  (found 2026-09-25 while setting up the repo; not yet checked in the run manifests).
