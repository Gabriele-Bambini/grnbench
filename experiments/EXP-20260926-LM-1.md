# EXP-20260926-LM-1: Confirmatory - does the motif prior lift RegDiffusion and GRNBoost2 on real data?

## 1. Registration (before the run)

- type: **confirmatory** (pre-registration = the commit that adds this file, pushed before any
  of the four models below was run on any dataset of this list)
- owner: LM (agent-run)   issue: #10   registered: 2026-09-26
- follows: EXP-20260925-LM-1 (exploratory: on 12 other datasets, regdiffusion_motif vs regdiffusion
  +0.222 and grnboost2_motif vs grnboost2 +0.143 AUPRC ratio) and EXP-20260925-LM-2 (confirmatory,
  Pearson only: pearson_motif vs pearson_signed +0.182 on these 20 datasets)
- hypothesis: co-primary, directional. H1: `regdiffusion_motif` (RegDiffusion edges rank-producted
  with the cisTarget motif prior) recovers the CollecTRI evaluation half better than
  `regdiffusion` alone. H2: `grnboost2_motif` recovers it better than `grnboost2` alone.
- primary endpoint: AUPRC ratio (AUPRC / prevalence; 1 = random) on the CollecTRI evaluation half,
  **auto** pipeline arm (the engine's screened choice), mean over contexts within a dataset.
- secondary endpoints (reported, not used for H1/H2): EPR; the baseline pipeline arm; each model's
  mean AUPRC ratio against random (1.0), descriptive only.
- unit of analysis: dataset. Planned n = 20; analysed n = datasets with a score for both members
  of a pair (printed per pair by the report).
- datasets: the 20 CELLxGENE datasets of EXP-20260925-LM-2 (`experiments/EXP-20260925-LM-2.datasets.tsv`;
  sha256 of every `data.h5ad` and `truth.json` in `experiments/datasets.tsv`). Why not fresh data:
  (1) none of the four models has ever been scored on them (the exploratory estimates above come
  from 12 other datasets); (2) their bytes are pinned by sha256, so the cluster copy is checked,
  not trusted; (3) the same datasets make these results directly comparable with the Pearson
  results of LM-2 (descriptive only, no test across experiments). What this costs: the motif prior
  and the pipeline choices on these datasets were already seen in LM-2 with Pearson, so the set is
  not blind to "the motif prior helps on these data". A fresh-set rerun would remove that.
- exclusion rules (fixed now): (a) a dataset whose download fails or whose sha256 does not match
  `experiments/datasets.tsv` is replaced by nobody and reported as missing (for `truth.json` a
  difference in line endings only is accepted, `data_manifest.py --check` reports it as `ok-eol`);
  (b) datasets with fewer than 50 reference edges among their genes are not scored
  (`MIN_REFERENCE_EDGES`); (c) a dataset where a model errors is dropped from the pairs involving
  that model only, and reported; (d) a dataset still unfinished after the job and one resubmission
  of the same commit (resource limits: TIMEOUT or out of memory) is reported as missing;
  (e) no other exclusion, no outlier removal.
- comparison family: `real_bench.DECLARED_PAIRS` restricted to the models run =
  {(regdiffusion_motif, regdiffusion), (grnboost2_motif, grnboost2)}, both directions =
  4 directed hypotheses per metric and arm.
- test: paired t over datasets, two-sided per direction, via `compare_units` for each pair
  (95% interval of the mean paired difference), Holm over the 4 directed hypotheses of the
  AUPRC ratio / auto family, alpha 0.05. For each of H1, H2: **supported** if
  p_Holm(motif > plain) < 0.05; **refuted** if p_Holm(plain > motif) < 0.05; otherwise
  inconclusive (not evidence of equality). Holm over the family already accounts for testing two
  co-primary hypotheses.
- primary comparison: regdiffusion_motif > regdiffusion | auprc_ratio | auto; grnboost2_motif > grnboost2 | auprc_ratio | auto
- smallest effect that matters: none declared.
- seeds: reference split seed 0 (`screen.split_reference`), cell subsample seed 0 (at most 3,000
  cells per context, `MAX_SCORE_CELLS`), scrublet seed 0, RegDiffusion seed 0 (1,000 steps, CPU),
  GRNBoost2 seed 42 (the adapter defaults); regulators = the 150 TFs with most reference targets
  in the data (`MAX_TFS`).
- models: regdiffusion, regdiffusion_motif, grnboost2, grnboost2_motif (exactly these four).

## 2. How it runs

  ```
  bash hpc/fetch_cistarget.sh $D/cistarget

  tar czf - -C <local data root> references | bash hpc/hpc.sh run "tar xzf - -C $D"

  ```
