# EXP-20260925-LM-2: Confirmatory - does the motif prior lift GRN recovery on fresh real datasets?

## 1. Registration (before the run)

- type: **confirmatory** (pre-registration = the commit that adds this file, pushed before any
  dataset of this list was downloaded or scored)
- owner: LM   issue: board issue opened at launch   registered: 2026-09-25
- follows: EXP-20260925-LM-1 (exploratory, same question, 12 other datasets)
- hypothesis (H1, primary, directional): on real scRNA-seq, `pearson_motif` (Pearson co-expression
  rank-producted with the cisTarget motif prior) recovers the CollecTRI evaluation half better
  than `pearson_signed` alone.
- primary endpoint: AUPRC ratio (AUPRC / prevalence; 1 = random) on the CollecTRI evaluation half,
  **auto** pipeline arm (the engine's screened choice), mean over contexts within a dataset.
- secondary endpoints (reported, not used for H1): EPR; the baseline pipeline arm;
  `pearson_motif` vs `motif_prior` (does expression add to the prior alone).
- unit of analysis: dataset. Planned n = 20 (list below); analysed n = datasets with a score for
  both members of a pair (printed per pair).
- datasets: `experiments/EXP-20260925-LM-2.datasets.tsv` (20 CELLxGENE Discover datasets, human 16 /
  mouse 4, 8 protocols), chosen by `benchmarks/fetch_cellxgene.py --max 20 --max-mb 60
  --organisms "Homo sapiens,Mus musculus" --exclude-ids experiments/EXP-20260925-LM-2.excluded_ids.txt
  --exclude-assay targeted` on the public listing of 2026-09-25. Excluded before selection: the 31
  dataset ids used by any earlier experiment (`EXP-20260925-LM-2.excluded_ids.txt`) and targeted
  panels (not transcriptomes).
- exclusion rules (fixed now): (a) a dataset whose download fails or whose sha256 cannot be recorded
  is replaced by nobody and reported as missing; (b) datasets with fewer than 50 reference edges
  among their genes are not scored (`MIN_REFERENCE_EDGES`, as in the code); (c) a dataset where a
  model errors is dropped from the pairs involving that model only, and reported; (d) no other
  exclusion, no outlier removal.
- comparison family: `real_bench.DECLARED_PAIRS` restricted to the models run =
  {(pearson_motif, pearson_signed), (pearson_motif, motif_prior)}, both directions =
  4 directed hypotheses per metric and arm.
- test: paired t over datasets, two-sided per direction, via `compare_units` for each pair
  (95% interval of the mean paired difference), Holm over the 4 directed hypotheses of the
  AUPRC / auto family, alpha 0.05. **H1 is supported** if p_Holm(pearson_motif > pearson_signed) < 0.05
  in that family; **refuted** if p_Holm(pearson_signed > pearson_motif) < 0.05; otherwise inconclusive.
- smallest effect that matters: none declared (the exploratory estimate was +0.23).
- primary comparison: pearson_motif > pearson_signed | auprc_ratio | auto
  (machine-readable restatement of H1 and its decision rule for `grnbench report`, added
  2026-09-25 before the run started; no content change)
- seeds: reference split seed 0 (`screen.split_reference`), cell subsample seed 0 (at most 3,000
  cells per context, `MAX_SCORE_CELLS`), scrublet seed 0; regulators = the 150 TFs with most
  reference targets in the data (`MAX_TFS`).
- models: pearson_signed, pearson_motif, motif_prior. RegDiffusion is **not** run: about 13 min per
  dataset per arm on this CPU (about 9 h for 20 datasets x 2 arms), it goes to an HPC experiment.

## 2. How it runs

- code: branch `lm/confirmatory-motif-prior`, commit recorded in the results folder (`CODE_COMMIT`),
  which includes the scrublet fix (PR #3: scikit-image present, doublet fallback recorded per arm)
  and `real_bench --keep-artifacts` for the explainability figures.
- environment: fresh venv from `requirements/lock-py311.txt` (Python 3.11.9, Windows), no torch.
- data: downloaded after this record was pushed, into a local folder outside the repo; sha256 of
  every file appended to `experiments/datasets.tsv` in the results PR.
- commands:
  ```
  python benchmarks/fetch_cellxgene.py --out <DATA>/cellxgene --max 20 --max-mb 60 --organisms "Homo sapiens,Mus musculus" --exclude-ids experiments/EXP-20260925-LM-2.excluded_ids.txt --exclude-assay targeted
  python benchmarks/real_bench.py plan --data-root <DATA> --out <RUN>/tasks.json
  GRNBENCH_CISTARGET_DIR=<cistarget> python benchmarks/real_bench.py run --tasks <RUN>/tasks.json --refs <references> --out <RUN> --jobs 3 --workroot <WORK> --models pearson_signed,pearson_motif,motif_prior --keep-artifacts
  python benchmarks/real_bench.py report --out <RUN>
  grnbench viz <RUN> ; grnbench report <RUN>
  ```
  (references and cisTarget files: the same files as EXP-20260925-LM-1, sha256 in `experiments/datasets.tsv`)
- machine: local laptop (Windows, 3 workers)
- report input: `benchmarks/results/EXP-20260925-LM-2`
- results: `benchmarks/results/EXP-20260925-LM-2/` (report, rows, figures, LaTeX); edge lists and
  processed data outside git.
