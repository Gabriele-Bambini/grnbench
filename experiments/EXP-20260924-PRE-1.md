# EXP-20260924-PRE-1: Engine mass test v1, synthetic, before fixes (pre-registry)

## 1. Registration
- type: exploratory (no pre-registration)
- owner: not recorded (agent run on a collaborator PC)
- question: does the automatic cleaning beat a standard pipeline on data with a known (planted) network?
- endpoint: recovery of the evaluation half of the planted network per model; unit = dataset
- datasets: simulator (`src/grnbench/simulate.py`), 19 presets x 3 + 40 random = 80 (seeded, `tasks` in the run)
- arms: baseline / rules / auto / auto_noref / oracle; models: pearson_signed, spearman_signed, clr

## 2. How it ran
- code: pre-git snapshot (Drive), `benchmarks/engine_bench.py plan|run|report`
- results: `benchmarks/results/engine-2026-09-24-v1-prefix/` (REPORT.md, all_rows.csv)

## 3. Results
- status: done, 72/80 completed, 8 errors from engine bugs (raw droplets, dataset-wide mito gate, ranking crash)
- headline (Wilcoxon on paired differences, not the compare_units path): auto vs baseline 83% wins,
  median +41%, p = 1.6e-11 (n = 71); per model Pearson +78%, Spearman +88%, CLR ties (15% wins);
  rules alone hurt CLR; auto without a reference = baseline (14% wins, p = 0.2).
- verdict: supports the engine on synthetic data only; synthetic gains are an upper bound (D-015).
